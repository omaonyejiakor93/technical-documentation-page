# Technical Documentation Page

A responsive technical documentation page built with HTML and CSS as part of the [freeCodeCamp Responsive Web Design Certification](https://www.freecodecamp.org/learn/).

## Features

- Semantic HTML structure
- Fixed sidebar navigation
- Internal section links for easy navigation
- Responsive design with media queries
- Follows accessibility best practices

## User Stories (freeCodeCamp)

- Main content is wrapped in #main-doc
- Navigation bar links correspond to content sections
- Minimum of 5 documentation sections
- Contains paragraphs, list items, and code snippets
- Navbar remains visible on larger screens
